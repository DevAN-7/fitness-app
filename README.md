# Fitness App

Is a react web application which allows users to browse excercises and search for excercise with detailed explanation of target muscle, equipment and description of how to do the excercise

- The api used has a limited amount of requst per month, so if it is a blank page it means we have reached the limit of the quota for the month

## Features

- Browse excercises
- Search excercises
- filter with different categories
- Details page for each excercise
- Youtube videos for each excercise
- related excercises

---

## Technologies Used

- ReactJS
- React router
- Material UI
- ExcerciseDB API (From RapidAPI)
- Youtube API
- JavaScript
- HTML & CSS

## Installation

### Step 1: Clone the repository

```bash
git clone https://github.com/auzair-17/fitness-app.git
```

### Step 2: Go to project directory

```bash
cd fitness-app
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start development server

```bash
npm run dev
```
